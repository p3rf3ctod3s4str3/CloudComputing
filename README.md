# Cloud Computing - Belén Céspedes

Proyecto académico para la asignatura **Computación en la Nube**.

## Estructura

- `index.html`: portada del proyecto.
- `html/sistema.html`: sistema principal.
- `css/estilos.css`: estilos del sitio.
- `js/app.js`: CRUD con LocalStorage.
- `js/firebase.js`: configuración y CRUD con Firebase Firestore.
- `img/logo.png`: imagen utilizada en la portada.

## Ejecutar

Puedes abrir `index.html` con Live Server en Visual Studio Code.

## Firebase

Para activar Firebase, reemplaza los valores `PEGA_AQUI` dentro de `js/firebase.js` por los datos de configuración de tu aplicación web en Firebase.

El proyecto está preparado para publicarse con **GitHub Pages**.
